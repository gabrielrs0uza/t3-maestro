# Configuração local

Copie para `config.local.md`, que não vai para o git, e preencha.

- **Dono:** nome de quem usa este chat mestre.
- **Merge já é deploy em:** repositórios em que merge na `main` publica sozinho.
  Se não houver, escreva "nenhum".
- **Linear:** `etiqueta: t3` para abrir chats a partir de issues, ou "não usa".

## Regras do time

Regras próprias do seu time, se houver.
