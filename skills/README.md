# Skills do maestro

Estas skills abrem chats com `t3_thread_launch`, como manda o `AGENTS.md`. Quando
houver conflito, o `AGENTS.md` vence.

Nada aqui autoriza merge, deploy, alteração em produção ou exclusão além das
duas exceções do bloco fixo do `AGENTS.md`.

Para usar num intérprete, cite no `message` o caminho absoluto do arquivo, porque
o intérprete não vê esta pasta por conta própria:
`<pasta do maestro>/skills/<nome>.md`.
